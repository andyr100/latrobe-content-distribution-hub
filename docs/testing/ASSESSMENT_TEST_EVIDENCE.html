Measured conclusion: local x10,000 exhausted the local Docker Desktop path: 9,971/10,000 samples timed out and an API-only restart was required. On final EC2 Linux, all 10,000 requests completed, with 17 ms median, 25 ms P95 and a healthy API afterward. This is strong final-deployment evidence, but it is not an apples-to-apples Internet latency comparison: the generator was co-located on EC2 and the local and EC2 hosts have different runtime resources.

Different ramp periods also mean throughput should not be compared as a service-capacity benchmark. A future sustained-load profile with a hold period is the appropriate next capacity test.
