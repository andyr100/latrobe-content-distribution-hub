Interpretation

x1–x1,000 completed with no errors. At x10,000 the local single-instance Next.js/SQLite API saturated: about 501 requests remained active, nearly all samples hit the configured 30-second timeout, and the API health check stopped responding. Restarting only the API container restored 200 OK, database connectivity and all eight feeds in approximately six seconds without deleting the volume.

Each thread sends one request and has a unique X-Client-Id. This proves staged client arrival volume, not 10,000 simultaneous sustained connections. Different ramp periods also mean throughput values are not directly comparable capacity benchmarks.
